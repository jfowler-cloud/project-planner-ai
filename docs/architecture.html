AI Backend

  • FastAPI + Bedrock/Anthropic Claude
    Python 3.12+ backend with Pydantic v2 validation. Supports both AWS Bedrock and direct Anthropic API for Claude model access.
  • SSE Streaming
    Real-time planning responses via Server-Sent Events. POST /api/v1/plan starts Step Functions execution; GET /api/v1/plan/status/{arn} polls for results.
  • Architecture Option Generation
    Generates 3-5 architecture approaches with security, observability, and testing built in. Parallel critical reviews (up to 10 categories) run via Step Functions Map state.
  • Scaffold AI Handoff
    Writes completed plan data to DynamoDB with session ID. One-click transfer to Scaffold AI for code generation and infrastructure-as-code.

Frontend Pages

  • Home
    Landing page with feature overview, demo mode, and quick-start entry point to the questionnaire.
  • Questionnaire
    3-step wizard built with react-hook-form + zod validation. Captures project basics, technical requirements, and preferences.
  • Planning
    SSE stream with real-time AI response display. Polls Step Functions execution status until architecture options are generated.
  • Results
    4-tab view (overview, architecture, costs, security). Selectable architecture options, critical reviews, and Scaffold AI handoff button.

Infrastructure

  • React 19 + Vite + Tailwind CSS
    Single-page application with Vite bundler and Tailwind CSS utility-first styling. Red accent palette (#e8001c).
  • Zustand State Management
    Lightweight global state for wizard flow. Session storage for cross-page data transfer between questionnaire, planning, and results.
  • React Router v7
    Client-side routing with useNavigate and useParams. Error boundaries on /planning and /results pages.
  • Dark/Light Mode
    CSS custom properties with pp- prefix. Dark mode default, preference persisted to localStorage, sun/moon toggle in navigation.

Integration

  • Scaffold AI Handoff
    Writes plan to DynamoDB, opens Scaffold AI with session ID. Structured JSON transfer with shared TypeScript types. Falls back to URL parameters if API unavailable.
  • Mermaid.js Diagrams
    Architecture diagrams rendered inline using Mermaid.js. Visualizes generated architecture options and data flow.
  • Export Options
    Markdown and JSON export formats for completed plans. PDF export planned but not yet implemented.
  • GitHub Repository Generation
    Generate a GitHub repo from a completed plan via POST /api/v1/generate-repo with X-GitHub-Token header authentication.
