Agents
apps/agents/ — Shared config and DB helpers
shared/config.py
Central AppConfig via Pydantic Settings. Tiered model selection: Haiku 4.5 (testing), Sonnet 4.5 (optimized), Opus 4.5 (premium). Max tokens 4096, temperature 0.3.
Bedrock model ID • deployment tier • review categories

boto3 resource • mirrors PSP db.py pattern

Portfolio standards constant (PORTFOLIO_STANDARDS) baked into AI system prompts for generate and review agents.
Lambda Functions
apps/functions/ — Python 3.12, Powertools, X-Ray tracing
generate_plan
Creates initial architecture plan from questionnaire input. Strands Agent with Bedrock generates recommended stack + 2-3 alternatives with Mermaid diagrams.
512 MB • 5 min timeout • Bedrock invoke
review_step
Runs one review iteration. Invoked 10x in parallel via Map state across categories: security, scalability, cost, reliability, performance, maintainability, DX, compliance, observability, DR.
512 MB • 5 min timeout • max concurrency 3
finalize_plan
Aggregates review findings from Map results, persists completed plan to DynamoDB project-planner-plans table.
512 MB • 5 min timeout • DynamoDB write
get_execution
Polls Step Functions execution status. Returns plan data on SUCCEEDED, error on FAILED/TIMED_OUT/ABORTED. Invoked by frontend via Cognito identity pool credentials.
256 MB • 30s timeout • states:DescribeExecution
Infrastructure
apps/infra/ — CDK v2 TypeScript, 3 stacks
DatabaseStack
Cognito User Pool + Identity Pool, DynamoDB tables, S3 + CloudFront hosting, SNS alarm topic, CloudWatch throttle alarms, monthly budget ($25 cap).
Groups: users, admins • OAC for S3 • PITR enabled
FunctionsStack
4 Lambda functions with PythonLayerVersion (shared + agents layers). Bedrock IAM policy, per-function CloudWatch error and P99 duration alarms.
Props: deploymentTier, modelId, plansTable, alarmTopic
WorkflowStack
Step Functions state machine with 3 modes: full flow, generateOnly, reviewOnly. Cognito identity pool role bindings for SFN start, Lambda invoke, and handoff table write.
30 min timeout • execution failure alarm • SFN metrics
Frontend
apps/web/ — React 19 + Vite + Tailwind
Pages (4)
Home landing, Questionnaire 3-step wizard (basics, technical, preferences), Planning execution progress, Results with architecture cards.
State Management
Zustand store (useWizardStore) tracks wizard step, questionnaire data, plan output, progress events, GitHub token (session-only), and repo URL.
API Layer
AWS SDK direct calls via Cognito identity pool credentials. startPlanExecution, startReviewExecution, pollExecution, exportToScaffold. No API Gateway.
Components
ThemeProvider (dark mode default), ErrorBoundary, ScaffoldIntegration slide-out panel for plan handoff to Scaffold AI via DynamoDB session.

Authentication (Cognito)

Resource Configuration Details
User Pool ProjectPlanner-Users Email sign-in, auto-verify email, self-signup disabled, password: 8+ chars (upper, lower, digits), RETAIN on delete
Groups users, admins Two Cognito user pool groups for role-based access control
Web Client ProjectPlanner-WebClient Auth flows: USER_PASSWORD_AUTH, USER_SRP_AUTH. Prevent user existence errors enabled.
Identity Pool ProjectPlanner-IdentityPool Authenticated only. Role grants: SFN StartExecution, Lambda Invoke (get_execution), DynamoDB write (handoff table).
